# HOEW
Hybrid-Oriented Engine for Weak hardware

# Важно
Перед использованием этого **игрового движка** (а точнее ***API***) советуется прочитать этот фаил

# Фаилы
Types является ролью базовых struct
Render делает работу рендера на GDI а также в новых версиях на OpenGL для 3D
Main является управляющим фаилом всего движка
